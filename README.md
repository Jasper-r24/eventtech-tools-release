# EventTech Toolbox – Releases

App für Veranstaltungstechniker. Alle Tools offline nutzbar, kein Login erforderlich.

---

## Aktuelle Version: 1.8.0

### Installation
1. APK unter **Releases** herunterladen
2. Auf dem Android-Handy öffnen
3. Beim ersten Mal: „Aus unbekannter Quelle installieren" erlauben

### Update
Die App meldet sich selbst wenn eine neue Version verfügbar ist.
Einfach im Dialog auf **„APK herunterladen"** tippen.

---

## Enthaltene Tools

| Tool | Funktion |
|---|---|
| **DMX-Rechner** | Startadresse ↔ DIP-Schalter |
| **Farben** | Farbpool & Kelvin → RGB |
| **Wurfweite** | Lichtkegel berechnen (Winkel / Distanz / Durchmesser) |
| **Delay-Rechner** | Audio-Laufzeit bei gegebener Distanz |
| **dB-Meter** | Schallpegelmesser mit Verlaufsgraph |
| **Einheiten** | Länge · Gewicht · Leistung umrechnen |
| **Traverse-Planer** | Lampen symmetrisch planen + Plan exportieren |
| **Strom** | Lastverteilung · Kabel · Phasen · Generator |
| **Checklisten** | Aufgaben & Vorlagen verwalten |
